# Производственный процесс: где что лежит и как продолжать

## 1. Материалы

**Мастер-папка изображений:** [Google Drive / ПРЕЗА](https://drive.google.com/drive/folders/1KswYJUyQAkCllvvuWVEDZO8OL9fTUbGx) — ровно 25 PNG.

**Проверенный порядок:** `data/slides.json`. В нём сохранены исходное имя каждого PNG, идентификатор файла Drive, URL и целевой локальный путь.

**Ранее созданные резервные артефакты:** PowerPoint с заметками, PDF слайдов, PDF/Markdown заметок, проверочный чеклист. Их готовили как страховку, они **не заменяют HTML-приложение**. Файлы не загружены в этот GitHub.

## 2. Как получить локальный офлайн-комплект картинок

1. Скачать 25 оригинальных PNG из Drive в одну локальную папку, сохранить исходные имена файлов.
2. Установить Node.js (или использовать уже установленный).
3. Из корня репозитория выполнить:

   ```powershell
   node tools/import-slides.mjs "C:\\Users\\USERNAME\\Downloads\\ПРЕЗА"
   ```

4. Скрипт проверит, что все 25 файлов на месте и имеют формат PNG 16:9. Затем скопирует их под именами `assets/slides/01.png` ... `25.png` (исходники не изменяет).
5. Файл 25 в Drive **содержит оборванную фразу внизу**; его нужно заменить исправленным экспортом или исправить при показе отдельным слоем. Не забывать об этом.

Скрипт не умеет читать закрытые Drive URL напрямую, не нужен токен Google Drive, не содержит секретов.

## 3. Как строить браузерную версию

- Сначала скопировать **01–05**, затем сделать два окна и проверить синхронизацию.
- У ведущего должны быть полные сценарные заметки, а не подписи на три слова. Это отдельные текстовые данные.
- Изображения — локальные файлы; внешние ссылки из манифеста служат для восстановления происхождения, а не для показа аудитории.
- При браузерном тестировании: `python -m http.server 8000` из корня проекта, открыть `http://localhost:8000/` (когда HTML появится). Не использовать `file://` как единственный тест двух окон.
- Для Windows выбрать `Win + P → Расширить`; переместить окно audience на проектор.
- Q&A показывать в живой вкладке/встроенным реальным экраном, а не подделкой.

## 4. История создания и сохранённые решения

- Исходный замысел — интеллектуальное шоу на 90 минут, не обзор ChatGPT и не лекция по ML.
- Первый HTML-прототип с грубой перерисованной графикой и урезанным текстом **отвергнут**.
- Выбран art-first: 25 качественных изображений с короткой крупной типографикой; рассказы хранятся отдельно.
- PNG генерировались малыми партиями, затем проверялся комплект: сначала 20/25, потом 25/25.
- Исправление картинки 25 было сделано при экспорте в PPTX/PDF, оригинал в Drive остался прежним.
- Теперь конечная цель — **HTML presenter/audience**, а PPTX/PDF резерв.
