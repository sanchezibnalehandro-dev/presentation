Как добавить презентацию

Студия принимает готовые изображения. PDF и PPTX предварительно конвертируются в PNG на вашем компьютере, без передачи файлов в интернет.

01 · Уже есть PNG или JPG

Закрой это окно → «↑ Изображения» → выбери все слайды. Если загружен JSON с image-кадрами, количество картинок должно совпадать.

02 · Есть PDF

В комплекте уже есть локальный конвертер. В терминале из папки репозитория presentation:

py -m pip install PyMuPDFpy course-studio/tools/prepare_deck.py "C:\Путь\Презентация.pdf" --slug my-deck

После конвертации загрузи созданный deck.json кнопкой «↑ Сценарий JSON». PNG будут лежать в папке private-decks.

03 · Есть PPTX

В PowerPoint: «Файл → Сохранить как / Экспорт → PNG → Все слайды». После этого кнопка «↑ Изображения». Можно также экспортировать PPTX в PDF и использовать шаг 02. Для прямой обработки PPTX через скрипт нужен LibreOffice.

Прямой импорт PDF/PPTX в браузере пока не реализован. Эта кнопка открывает справку и не запускает конвертацию.
