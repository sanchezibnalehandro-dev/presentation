# COURSE STUDIO · отдельный пульт записи курса

Это **изолированный модуль** внутри репозитория `presentation`. Основное шоу «Цифровые неандертальцы» и его файлы не изменяются.

## Важно про приватность
Репозиторий публичный. **Никакие полные сценарии платного курса сюда не добавлять**. Студия принимает **локальный JSON-файл** через кнопку «Загрузить сценарий». Файл читается браузером, хранится в sessionStorage вкладки (до закрытия) и не отправляется на сервер. Вторая вкладка получает только визуальную часть кадра, не суфлёр. На чужом компьютере после работы закрывать вкладки и очищать данные сайта.

## Быстрый запуск
1. Из корня репозитория: `python -m http.server 8000` (Windows: `py -m http.server 8000`).
2. Открыть `http://localhost:8000/course-studio/`.
3. Нажать «Загрузить сценарий» и выбрать файл с private course data (отдельно от GitHub).
4. Нажать «Экран записи». Перенести второе окно на расширенный монитор; F11.
5. Записывать окно зрителя через OBS или демонстрацию экрана. Пульт **не захватывать**.
6. Стрелки / Space переключают кадры; таймер, размер текста, чёрный экран доступны в пульте.
7. Для реальных экранов ChatGPT есть особый кадр `kind:"live"`: это **режиссёрская плашка**, затем оператор переключает OBS на реальное окно сервиса. Поддельных скриншотов нет.

## Формат JSON
```json
{
  "course": "ChatGPT от А до Я за 7 дней",
  "lessons": [
    {
      "id": "D01-L01",
      "title": "Что такое ChatGPT",
      "durationMin": 8,
      "status": "ready",
      "cues": [
        {
          "id": "D01-L01-C01",
          "at": "00:00",
          "title": "Тезис",
          "visual": {
            "kind": "statement",
            "kicker": "ДЕНЬ 1 · УРОК 1",
            "day": "01 / 07",
            "headline": "Главная мысль кадра",
            "subline": "Крупно, без мелкого текста",
            "bullets": ["Первый пункт", "Второй пункт"]
          },
          "speech": ["Полная речь ведущего, доступная только в пульте."],
          "action": "Что нажать и показать на экране.",
          "production": "Режиссёрские инструкции, источник OBS, монтаж.",
          "check": "Условие перехода к следующему кадру."
        }
      ]
    }
  ]
}
```

`visual.kind`: `title`, `statement`, `compare` (две `columns: [{title,body},...]`), `steps` (bullets), `question`, `live`, `outro`. Каждый кадр 16:9, текст заполняется безопасно через `textContent` (без HTML). Это типографический инструмент для обучения; художественные PNG из основного шоу остаются нетронутыми.

## Границы MVP
- Два окна должны быть на **одном компьютере и одном origin**. Синхронизация использует `postMessage` + подтверждение подключения; нет backend.
- Проверка через реальный второй дисплей/OBS **не выполнена** до теста на машине ведущего.
- Не записывает видео и звук автоматически; захват выполняет OBS/другая программа.
- Никаких платёжных данных, секретов или персональных сведений в JSON.
- Если второе окно закрыть, пульт продолжает работать, его можно открыть снова.
- Исходная презентация доступна как прежде по корню сайта.

## Acceptance test
- Открыть окно записи; проверить смену первого → второго → третьего кадра.
- Убедиться, что в окне записи нет суфлёра/режиссёрских заметок.
- Ведущий видит полные `speech` и `action`; Notes можно скроллить отдельно.
- Перезагрузить viewer: должен запросить и показать текущий кадр.
- Проверить увеличение текста, таймер, blackout и возврат.
- Показать кадр `live`, переключить OBS на реальный ChatGPT.
- Закрыть viewer и снова открыть. Проверить состояние соединения.
