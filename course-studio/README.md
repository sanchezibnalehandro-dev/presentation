# COURSE STUDIO v2 · студия записи с двумя окнами

**Для курса «ChatGPT для маркетинга»**. Изолированный модуль публичного репозитория. Исходное выступление «Цифровые неандертальцы» в корне проекта **не меняем**.

Студия управляет отдельным чистым изображением 16:9 для записи и пультом ведущего: текущий/следующий кадр, дословная речь, действия, заметки OBS, таймер и навигация. **Studio не записывает звук и видео**: запись делает OBS.

## Что изменилось в v2
- **image:** готовые PNG/JPG/WebP, включая страницы PDF/PowerPoint, без перерисовки и без обрезания по умолчанию (\`contain\`).
- **live:** сцена-переход к настоящему ChatGPT/таблице/браузеру; в OBS источник меняется вручную.
- **html:** старые типографические кадры остаются для простых титров и служебных карточек.
- **blackout:** временный чёрный кадр, в том числе кнопка пульта.
- **NEXT preview:** изображение следующего кадра, а не только его заголовок.
- Локальная загрузка готовых **PNG/JPG/WebP** из окна браузера (файлы остаются в памяти вкладки). Viewer получает только соответствующее изображение, **никогда не получает speech, action, production**.
- Скрипт подготовки PDF/PPTX: страницы превращаются в локальные PNG и \`deck.json\`, которые доступны без интернета.

## Быстрый запуск: готовый набор с NotebookLM PDF
1. Скачать приватный ZIP с 12 слайдами и сценарием для 3 уроков (хранить вне GitHub).
2. Из ZIP распаковать **папку** \`private-decks/marketing-diagnostics\` **в** \`presentation/course-studio/private-decks/marketing-diagnostics\`.
3. В корне \`presentation\` запустить \`py -m http.server 8000 --bind 127.0.0.1\` (или \`python -m http.server 8000 --bind 127.0.0.1\`).
4. Открыть \`http://localhost:8000/course-studio/\`.
5. Нажать **«Сценарий JSON»** и выбрать \`ChatGPT_MARKETING_D01_STUDIO_v2.json\` из ZIP.
6. Нажать **«Экран записи»**, перенести отдельное окно на второй дисплей (Windows: Win+P → Расширить) и вручную нажать F11.
7. Настроить OBS: источник окно записи/дисплей для слайдов, другой источник для настоящего ChatGPT/документа. На cue \`live\` переключать OBS вручную.
8. Навигация: стрелки, Space, кнопки; текст регулируется A−/A+.

### Быстрый импорт изображений без конвертера
Кнопка **«↑ Изображения»** принимает сразу PNG/JPG/WebP. Файлы сортируются по номеру (01, 02, 10).
- Если загружен JSON со сценами \`image\`, число импортированных изображений должно **строго совпадать** с числом таких сцен в текущем сценарии; они будут привязаны последовательно.
- Если открыт исходный демонстрационный сценарий, из картинок автоматически составляется простая презентация с заглушками заметок.
- Изображения из этого способа существуют **только в памяти текущей вкладки**. После перезагрузки импортируйте их повторно. Для воспроизводимого проекта используйте конвертер и локальную папку.

## Конвертация PDF / PPTX → PNG + локальный JSON
Один раз (если зависимости нет): \`py -m pip install PyMuPDF\`.

Пример из корня репозитория:
\`\`\`powershell
py course-studio/tools/prepare_deck.py "C:\Путь\ChatGPT Marketing Diagnostics.pdf" --slug marketing-diagnostics
\`\`\`
Получим \`course-studio/private-decks/marketing-diagnostics/slide-001.png\` … и \`deck.json\`. Этот JSON содержит **заглушки** речи, поэтому для съёмки лучше подготовить свой сценарий по примерам ниже либо загрузить приватный сценарий из комплекта.

**PPTX:** скрипт принимает PPTX при наличии установленного LibreOffice; если его нет, экспортируйте PPTX из PowerPoint в PDF и используйте PDF-вход. Прямой импорт PDF/PPTX **в браузере пока не реализован**. При конвертации PPTX проверьте шрифты и компоновку: LibreOffice иногда меняет оформление относительно PowerPoint. Весь рендер выполняется на вашем компьютере, исходники не уходят в сторонние сервисы.

Проверить комплект:
\`\`\`powershell
node course-studio/tools/check-deck.mjs "course-studio/private-decks/marketing-diagnostics/deck.json"
\`\`\`
Или передать путь к приватному съёмочному JSON: \`node course-studio/tools/check-deck.mjs "C:\Путь\ChatGPT_MARKETING_D01_STUDIO_v2.json"\`.

## Формат сцен
JSON хранит \`lessons[]\`, каждый содержит \`cues[]\` с \`visual\` (или \`view\`), \`speech[]\`, \`action\`, \`production\`, \`check\`. Старые \`visual.kind\` продолжают работать.

\`\`\`json
{
  "schemaVersion": 2,
  "course": "ChatGPT для маркетинга",
  "lessons": [{
    "id": "D01-L01", "title": "Маркетинговая диагностика", "durationMin": 12,
    "cues": [
      {
        "id": "C01", "at": "00:00", "title": "Диагностика",
        "visual": {"kind":"image", "src":"private-decks/marketing-diagnostics/slide-001.png", "fit":"contain", "background":"#ffffff"},
        "speech": ["Что я говорю в суфлёре."],
        "action": "Что показываю или нажимаю.", "production": "OBS: SLIDES.", "check": "Когда перейти."
      },
      {
        "id": "C02", "at": "02:00", "title": "Переходим в ChatGPT",
        "visual": {"kind":"live", "headline":"Разбор брифа", "subline":"Откройте настоящий ChatGPT"},
        "speech": ["Комментарий к действию."],
        "action": "Открыть реальный браузер.", "production": "OBS: CHATGPT LIVE.", "check": "Проверка закончена."
      }
    ]
  }]
}
\`\`\`

Файл изображения ищется относительно \`course-studio/\` и никогда не должен ссылаться на внешние серверы. Для работоспособности viewer должен открываться тем же \`localhost:8000\`, что и пульт. Система не обещает синхронизацию между отдельными физическими устройствами.

## Безопасность и сохранение контекста
- Репозиторий **публичный**. Папка \`private-decks/\` исключена \`.gitignore\`. Не коммитить платный сценарий/данные реальных клиентов.
- Приватный JSON загружается в браузер локально, в \`sessionStorage\` текущей вкладки; это не защищённое хранилище и не шифрование. На чужом ПК закройте вкладку и очистите данные сайта. **Запускайте статический сервер с `--bind 127.0.0.1`**, иначе он может быть доступен по локальной сети.
- Импортированные \`File\` картинки доступны только до обновления вкладки; в viewer передаётся только визуальный кадр и бинарный File, не текст заметок.
- Не открывайте приватный комплект через публичный веб-хостинг без отдельной системы доступа. \`localhost\` рекомендуется для записи.
- Никаких «фейковых» интерфейсов ChatGPT в учебных слайдах; концептуальные иллюстрации должны так и называться.

## Качество изображения
- Страница PDF конвертируется в PNG **1920 пикселей по ширине** по умолчанию. При необходимости \`--width 2560\`.
- Режим \`contain\` сохраняет весь кадр, с небольшими полями для нестандартного aspect ratio; \`cover\` сознательно может обрезать края.
- Для видео 1080p мелкий шрифт исходного PDF может оказаться нечитабельным. Подготовьте крупные слайды и демонстрируйте детали увеличением в источнике OBS, не масштабируя весь интерфейс браузера.
- Соотношение исходного PDF NotebookLM близко к 16:9, поэтому поля минимальны.

## Проверка перед реальной записью
1. Пульт на мониторе 1, зрительский экран fullscreen на мониторе 2.
2. Проследить переходы 01→02→03 и обратный переход, включая смешанные сцены image → live → image.
3. Проверить, что viewer не показывает ни слова из суфлёра.
4. Перезагрузить viewer; кадр должен восстановиться после HELLO.
5. Проверить, что при неверном пути показывается понятная ошибка, а не бесконечный спиннер.
6. Проверить таймер, blackout, увеличение суфлёра, прокрутку и next preview.
7. Переключить OBS на настоящую вкладку ChatGPT и вернуться.
8. Сделать 60-секундную тестовую запись и прочитать мелкий текст при просмотре 1080p.

## Что проверено и что нет
- Синтаксис JS обновлённых файлов проверяется автоматически при подготовке к PR.
- Конвертер PDF протестирован на двухстраничном синтетическом файле, размеры изображений и JSON сверены.
- Браузерный прогон на реальном Windows + OBS **не проводился**. До этого не объявляем систему «проверенной на съёмочной машине».

## v2.1 — пульт записи после первого просмотра (2026-11-03)

- Кнопка «PDF/PPTX · помощь» показывает инструкции внутри студии вместо сырого README.md. Она НЕ конвертирует PDF/PPTX непосредственно в браузере. Для конвертации предназначен локальный prepare_deck.py или экспорт из PowerPoint в PNG.
- Вертикальный разделитель колонок двигается мышью. Двойной щелчок сбрасывает 40/60. При фокусе на разделителе стрелки меняют ширину на 2%, с Shift на 8%, Home сбрасывает. Значение сохраняется на этом компьютере.
- В области суфлёра отображается ТОЛЬКО речь из speech[]. Действие из action помещено в отдельную нижнюю служебную область «НЕ ЧИТАТЬ». production и check не отображаются, но остаются допустимыми полями в старых JSON.
- A− / A+ меняют только речь (16–42 px). Настройки ширины и размера сохраняются в localStorage, сам сценарий по-прежнему в sessionStorage.
- Для проверки: открыть диалог импорта и закрыть; перетащить разделитель; сменить кадр; проверить пустое действие, шрифты, память ширины после обновления и отсутствие суфлёра в viewer.
- Данная доработка относится к UX, редактура текста уроков остаётся самостоятельной задачей.


## Запуск одним двойным щелчком на Windows

Начиная с версии v2.2 в корне репозитория есть **`START_COURSE_STUDIO.cmd`**. Открой его двойным щелчком; не нужно отдельно открывать терминал. Запускатель находит Python 3 (py или python), проверяет доступный локальный порт 8000–8010, повторно использует уже работающую Course Studio и открывает `http://localhost:<порт>/course-studio/` в браузере. Если 8000 занят другой программой, выбирает свободный порт. Сервер привязан только к 127.0.0.1 и не доступен по LAN.

Запускатель находится **в корне `presentation`**, рядом с README.md. Можно создать ярлык для него на рабочем столе через контекстное меню Windows. Запускатель не делает автообновления Git, не загружает материалы в сеть и не устанавливает зависимости. Python должен быть установлен, как и при ручном `py -m http.server`. Если сервер стартовал, он работает в фоне до завершения процесса Python или выключения компьютера; повторное нажатие не запускает второй сервер.

При проблемах запуска диагностический лог хранится в `%LOCALAPPDATA%\SanchezCourseStudio\server-<порт>.log`. Перезапуск сервера обычно не нужен для обновления статических файлов, достаточно обновить страницу браузера; при сбое можно завершить связанный процесс Python через Диспетчер задач. Для ручного запуска остаётся команда `py -m http.server 8000 --bind 127.0.0.1` **из корня репозитория**.

Проверка: `py -m unittest discover -s course-studio/tools/tests -v` (проверяет распознавание Course Studio, занятые порты и повторное использование сервера).
