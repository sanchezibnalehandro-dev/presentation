# Цифровые неандертальцы — HTML-презентация

**Интеллектуальное шоу про искусственный интеллект, 90 минут, 25 слайдов.**

Это **производственный репозиторий** для веб-версии выступления, а не ещё одна коллекция презентационных шаблонов. Наша цель — **два экрана**: на проекторе показывается только шоу, у ведущего на ноутбуке — изображения, подробные заметки, таймер и управление.

## Текущее состояние

- ✅ Разработана драматургия выступления и сценарные заметки к 25 слайдам.
- ✅ Сгенерированы и сверены 25 кинематографичных PNG 16:9.
- ✅ Собраны резервные PowerPoint/PDF со сценарием (созданы ранее).
- ✅ Оригиналы PNG лежат в [папке «ПРЕЗА» на Google Диске](https://drive.google.com/drive/folders/1KswYJUyQAkCllvvuWVEDZO8OL9fTUbGx).
- 🔲 HTML-оболочка с **раздельными экраном ведущего и экраном аудитории** ещё не реализована.
- 🔲 Для слайдов 21, 22, 24 потребуются реальные экраны Live Q&A / TASIGO либо переключение в браузер.
- 🔲 Настоящие URL/QR для Q&A и материалов мероприятия пока не зафиксированы.

## Принцип

**Изображения уже сделаны. Не перерисовываем их HTML/CSS.** Веб-оболочка должна лишь надёжно показывать слайды и помогать ведущему. Заметки — для ведущего, не для аудитории. Никаких миниатюрных абзацев и декоративных интерфейсов на проекторе.

Начинаем с **MVP на первых пяти настоящих слайдах**: независимые окна ведущего/аудитории, синхронная смена, заметки и таймер. Только после проверки UX подключаем остальные двадцать и живой Q&A.

## Важное

Репозиторий публичный. Не коммитить токены, пароли, частные ссылки комнат Q&A, приватные данные участников и другие секреты. Не обещать офлайн-показ, пока изображения не включены в локальный комплект: **ссылки на Google Диск в манифесте — это каталог исходников, а не офлайн-хостинг**.
