# Цифровые неандертальцы · Course Studio

> **Сверка 16.11.2026:** здесь **два самостоятельных локальных инструмента**, а не две функции одной программы. «Цифровые неандертальцы» (корневые `index.html`, `audience.html`) — сценическая презентация на 25 слайдов с отдельным пультом и экраном зала. **Course Studio** (`course-studio/`) — независимая студия записи курсов с суфлёром и вторым окном. Никакого общего состояния, встроенного переключения или общей библиотеки сценариев у них нет. [PR #2](https://github.com/sanchezibnalehandro-dev/presentation/pull/2) изменяет только Course Studio и **пока не слит**.

| Что открыть | Для чего | Как запустить на Windows |
| --- | --- | --- |
| **«Цифровые неандертальцы»** | Выступление, 25 PNG, полный сценарий и экран аудитории | `START_PRESENTATION.cmd` открывает `index.html` напрямую; альтернативный локальный сервер: `py tools/launch_presentation.py` |
| **Course Studio** | Запись уроков, суфлёр, действия, локальный импорт изображений/сценариев и окно для OBS | `START_COURSE_STUDIO.cmd` запускает localhost-сервер, открывает `/course-studio/`; требуется Python 3 |

**Не смешивать запуски:** `START_PRESENTATION.cmd` сейчас **не** вызывает `tools/launch_presentation.py`, он просто открывает файл в браузере. А Course Studio для приватных локальных наборов необходимо запускать через сервер с привязкой к `127.0.0.1`; файлы курса не публиковать в GitHub.

**Интеллектуальное шоу про искусственный интеллект, 90 минут, 25 слайдов.**

Это раздел **сценического инструмента «Цифровые неандертальцы»**, отдельно от Course Studio. Исходные художественные PNG не перерисовываются HTML/CSS. Наша цель — **два экрана**: на проекторе показывается только шоу, у ведущего на ноутбуке — изображения, подробные заметки, таймер и управление.

## Принцип

**Изображения уже сделаны. Не перерисовываем их HTML/CSS.** Веб-оболочка должна лишь надёжно показывать слайды и помогать ведущему. Заметки — для ведущего, не для аудитории. Никаких миниатюрных абзацев и декоративных интерфейсов на проекторе.

**Комплект 25 слайдов уже закоммичен.** Пульт, окно аудитории, заметки и QR-экраны реализованы. Текущая синхронизация окон использует `postMessage` (не считать старые упоминания BroadcastChannel актуальным контрактом). **Не подтверждена приёмка на настоящем ноутбуке/проекторе**, а внешние Q&A- и Drive-ссылки требуют проверки непосредственно перед выступлением.


## Запуск сценической презентации на ноутбуке

1. Скачать код репозитория (**Code → Download ZIP**) и распаковать либо выполнить `git clone https://github.com/sanchezibnalehandro-dev/presentation.git`.
2. В папке репозитория запустить сервер: `python -m http.server 8000` (Windows также может использовать `py -m http.server 8000`). Установка npm и сборка не нужны.
3. В браузере открыть **http://localhost:8000/**. Это твой пульт. Нажать **«Экран аудитории»**.
4. В Windows нажать **Win + P → Расширить**, перенести открывшееся окно аудитории на проектор и нажать **F11** в этом окне. На ноутбуке оставить пульт.
5. Переключать кнопками или **←/→, Space, Home/End**; в заметках есть регулировка размера текста. Таймер запускается вручную кнопкой **«Таймер»**.
6. Проверить, что смена слайда на пульте сразу отражается на проекторе, а заметки остаются невидимыми для зала. Перезагрузить окно аудитории, проверить восстановление текущего слайда.

**Перед запуском:** `node tools/check-mvp.mjs` проверяет **только исторический первый срез 01–05**. Он **не подтверждает** комплектность остальных 20 изображений и полного сценария. Скрипт `tools/launch_presentation.py` при серверном запуске отдельно проверяет наличие всех 25 PNG, но тоже не заменяет тест с проектором.

**Ограничения:** в коде есть все 25 сцен и QR-экраны, но реальный гостевой путь Q&A, ссылка материалов, доступность внешних адресов и работа на двух расширенных дисплеях **не подтверждены актуальной полевой проверкой**. Сами PNG локальны и не требуют интернета.

## Важное

Репозиторий публичный. Не коммитить токены, пароли, частные ссылки комнат Q&A, приватные данные участников и другие секреты. Все 25 PNG **уже включены в GitHub**. Google Диск остаётся каталогом оригиналов, а не необходимым источником изображений при локальном показе. **Ссылки на Google Диск в манифесте — каталог исходников, а не офлайн-хостинг**.

### Быстрый запуск Course Studio (Windows)

Для отдельной студии записи курса используйте двойной щелчок по [`START_COURSE_STUDIO.cmd`](START_COURSE_STUDIO.cmd) в корне репозитория. Он запускает локальный сервер и открывает браузер, если Python установлен. Повторное нажатие использует работающий сервер. Подробности — [Course Studio](course-studio/README.md).
