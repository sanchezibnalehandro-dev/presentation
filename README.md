# Цифровые неандертальцы — HTML-презентация

**Интеллектуальное шоу про искусственный интеллект, 90 минут, 25 слайдов.**

Это **производственный репозиторий** для веб-версии выступления, а не ещё одна коллекция презентационных шаблонов. Наша цель — **два экрана**: на проекторе показывается только шоу, у ведущего на ноутбуке — изображения, подробные заметки, таймер и управление.

## Принцип

**Изображения уже сделаны. Не перерисовываем их HTML/CSS.** Веб-оболочка должна лишь надёжно показывать слайды и помогать ведущему. Заметки — для ведущего, не для аудитории. Никаких миниатюрных абзацев и декоративных интерфейсов на проекторе.

**MVP на первых пяти настоящих слайдах уже закоммичен.** Независимые окна, синхронная смена по BroadcastChannel, восстановление слайда, заметки и таймер есть в коде. **Следующий этап — открыть на двух экранах и проверить UX**, только затем подключать остальные двадцать и живой Q&A.


## Запуск MVP на ноутбуке

1. Скачать код репозитория (**Code → Download ZIP**) и распаковать либо выполнить `git clone https://github.com/sanchezibnalehandro-dev/presentation.git`.
2. В папке репозитория запустить сервер: `python -m http.server 8000` (Windows также может использовать `py -m http.server 8000`). Установка npm и сборка не нужны.
3. В браузере открыть **http://localhost:8000/**. Это твой пульт. Нажать **«Экран аудитории»**.
4. В Windows нажать **Win + P → Расширить**, перенести открывшееся окно аудитории на проектор и нажать **F11** в этом окне. На ноутбуке оставить пульт.
5. Переключать кнопками или **←/→, Space, Home/End**; в заметках есть регулировка размера текста. Таймер запускается вручную кнопкой **«Таймер»**.
6. Проверить, что смена слайда на пульте сразу отражается на проекторе, а заметки остаются невидимыми для зала. Перезагрузить окно аудитории, проверить восстановление текущего слайда.

**Ограничения:** реализованы только сцены 01–05 из 25, настоящие Live Q&A/QR ещё не подключены. Локальный показ 01–05 не требует интернета после загрузки: изображения лежат в самом репозитории. Проверка на конкретном компьютере ещё впереди.

## Важное

Репозиторий публичный. Не коммитить токены, пароли, частные ссылки комнат Q&A, приватные данные участников и другие секреты. Первые пять PNG **уже включены** в локальный комплект MVP; остальные двадцать пока только на Google Диске. **Ссылки на Google Диск в манифесте — каталог исходников, а не офлайн-хостинг**.
