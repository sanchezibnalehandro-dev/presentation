# Инструкции для AI-ассистентов и Codex

## Прочитать перед любым изменением

1. `README.md`
2. `docs/DECISIONS.md`
3. `docs/BRIEF.md`
4. `docs/HTML_MVP.md`

6. `docs/FACTCHECK.md` — перед любыми изменениями содержания.

## Пользовательская цель

Создать презентационное **HTML-приложение с двумя окнами на одном ноутбуке**: полное изображение для аудитории; отдельный пульт ведущего с текущим и следующим изображениями, полными заметками, таймером и кнопками. ИИ выступление — интеллектуальное шоу «Цифровые неандертальцы», **25 уже готовых изображений**, ~90 минут.

## Непереговорные ограничения

- НЕ перепроектировать существующие художественные PNG в HTML-карточки, Canvas/SVG/элементарные иллюстрации.
- НЕ выбрасывать шутки, истории, факты и оговорки из сценария ради компактности заметок.
- НЕ добавлять муравьиный текст на экран аудитории.
- НЕ делать фальшивые интерфейсы Q&A/TASIGO, поддельные QR или несуществующие метрики.
- НЕ превращать MVP в платформу мероприятий (backend, логины, аналитика, CRM, и т. п.).
- НЕ коммитить секреты. Репозиторий публичный.
- Не утверждать, что приложение работает без интернета, если изображения подгружаются из Drive/CDN.
- Уважать правильные фактические оговорки из `docs/FACTCHECK.md`.
- Не трогать существующие PPTX/PDF/Drive файлы без отдельной необходимости.

## Правильный порядок работы

1. **Первый MVP на 5 слайдах**, с настоящими изображениями 01–05 и заметками.
2. Отдельное окно аудитории и синхронное переключение через браузерный канал (предполагается `BroadcastChannel`).
3. Проверка UX на двух расширенных экранах: чтение, навигация, перезагрузка окна, переключение браузера на Q&A.
4. Подключить остальные 20 слайдов после успешной проверки.
5. Подключить реальные внешние ресурсы/QR только после получения настоящих URL.

## Состояние исходников

- `data/slides.json` содержит точные имена PNG и verified Google Drive file URLs.
- `assets/slides/xx.png` — **пока только предполагаемые локальные пути**, файлов в GitHub ещё нет.
- Полные ранее подготовленные заметки: `Цифровые_неандертальцы_заметки_выступающего.md` из предыдущей сборки. **Пока в этот репозиторий не перенесены**; не объявлять заметки встроенными в HTML до импорта.
- `docs/ROADMAP.md` отражает следующие задачи.
- Окончание слайда 25: оригинальный PNG содержит оборванную фразу, в PPTX/PDF исправлено. См. `docs/FACTCHECK.md`.

## Definition of Done для первой версии

Ведущий с ноутбука управляет реальными первыми 5 PNG, на втором дисплее аудитория видит только соответствующую картинку, заметки не раскрываются, смена идёт синхронно, позиции восстанавливаются после обновления и интерфейс реально удобен для чтения с расстояния ~50–70 см.

Не писать полный набор возможностей без теста вертикального среза.
